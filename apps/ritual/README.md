# Тихий свет

Многостраничная демонстрационная витрина 007-А, опубликованная под /directions/sites/ritual/ на основном домене. На главной четыре сцены переключаются прокруткой или кнопками. Каталог, услуги и памятка доступны по обычным ссылкам. Тексты, шрифты и визуализации размещены в проекте. Форм заявок, оплаты, счётчиков и внешних виджетов нет.

## Сборка

Из apps/ritual выполните:

```sh
npm ci
npm run lint
npm run build
npm run typecheck
npm run verify
node scripts/stage-export.mjs
```

Next.js создаёт статический экспорт в out/. Скрипт stage-export переносит его в directions/sites/ritual/. Публикуйте исходники и соответствующий экспорт одним коммитом в основной проект GitHub Pages.

## Редактирование

Тексты и характеристики каталога находятся в src/lib/collection.ts, описания услуг — в src/lib/ceremonies.ts. Главная находится в src/app/page.tsx, сцены обложки — в src/components/ScrollCover.tsx. Изображения из public/plates/ — художественные визуализации для демонстрационного проекта.
